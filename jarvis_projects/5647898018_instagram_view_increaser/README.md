# Instagram View Increaser
A Python script to increase Instagram video views without requiring a username and password
## Setup
1. Install the required dependencies by running `pip install -r requirements.txt`
2. Run the script by executing `python main.py --video_link <video_link> --num_views <num_views>`
## Note
This script uses a headless Chrome browser to increase video views. It may not work if Instagram detects the automated browser.
